53. Maximum Subarray

language via LeetCode
Medium check_circle Acceptance: 50.4% thumb_up 34.8K

Given an integer array nums, find the contiguous subarray (containing at least one number) which has the largest sum and return its sum.

A subarray is a contiguous part of an array.

Subarray Sum Visualizer Max: 6
-2 1 -3 4 -1 2 1 -5 4
insights Maximum contiguous window spans index 3 to 6: [4, -1, 2, 1]
Example 1
Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: [4,-1,2,1] has the largest sum = 6.
Example 2
Input: nums = [1]
Output: 1
Example 3
Input: nums = [5,4,-1,7,8]
Output: 23
Constraints:
  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
psychology Follow up:

If you have figured out the O(n) solution, try coding another solution using the divide and conquer approach, which is more subtle.

tips_and_updates Progressive hints unveil the underlying intuition step-by-step.
Hint 1 Conceptual Discovery
Have you considered Kadane's algorithm? Think about iterating through the array and keeping track of the current maximum subarray ending at the current position.
Hint 2 Local vs Global Optimum
Keep track of current subarray sum vs resetting. At every element x, decide whether to start fresh with x or extend the previous accumulated sum with current_sum + x.

1. Kadane's Algorithm (Standard DP)

O(N) Time • O(1) Space

Linear scan computing prefix totals dynamically, dropping prefixes that contribute negative value.

2. Divide & Conquer

O(N log N) Time • O(log N) Space

Recursively compute the maximum subarray in the left half, right half, or crossing the midpoint.

class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        # Kadane's Algorithm implementation
        max_so_far = nums[0]
        curr_max = nums[0]
        
        for x in nums[1:]:
            curr_max = max(x, curr_max + x)
            max_so_far = max(max_so_far, curr_max)
            
        return max_so_far
